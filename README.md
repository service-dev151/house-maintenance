## 🚀 How to Deploy on GitHub Pages

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com/) and create a new public repository (e.g. `house-maintenance-uae`).

2. **Upload Website Files**:
   - Upload all files from this folder directly into the root of your repository:
     - `index.html`
     - `style.css`
     - `script.js`
     - `assets/` (including `icons/` and `images/`)

3. **Enable GitHub Pages**:
   - In your GitHub repository, go to **Settings** > **Pages** (in the left sidebar).
   - Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
   - Select the branch: `main` (or `master`) and directory `/ (root)`.
   - Click **Save**.

4. **Your Site is Live**:
   - GitHub will provide your live URL (e.g. `https://<username>.github.io/house-maintenance-uae/`).
